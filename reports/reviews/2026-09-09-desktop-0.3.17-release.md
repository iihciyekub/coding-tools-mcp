**Coding Tools MCP Desktop 0.3.17 / Core 0.3.6 — macOS release verification**

Release date: 2026-09-09. Target: macOS arm64.

This release completes the lightweight desktop runtime work with two user-facing bootstrap improvements. A missing `uv` or `cloudflared` can be downloaded into the app's private data directory using pinned official release assets and SHA-256 verification; system Python, Homebrew and `/usr/local` are not modified. The runtime still ships as a small pure-Python wheel plus a hashed dependency manifest and prepares/caches its larger third-party environment outside the application bundle.

macOS `app_*` automation now prefers the bundled native **Coding Tools MCP App Helper**. The helper is compiled with the system Swift toolchain, is approximately 147 KiB after Developer ID signing, and has the stable code-signing identifier `com.codingtoolsmcp.app-helper`. Accessibility, CGEvent input, menu operations, UI snapshots and window screenshots therefore execute under the helper's stable signed identity rather than a versioned external Python interpreter. Source/CLI usage retains the original direct Python implementation as a fallback.
